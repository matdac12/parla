    Dictation & hotkey

    How you start, lock and stop a dictation, and what you see while talking.

    Hotkey

    With two or more modifiers (default Ctrl+Alt+Space), holding just the modifiers is push-to-talk and tapping the full shortcut locks it hands-free (press the modifiers again to stop). A shortcut like Ctrl+Shift+F9 is tap to start, tap to stop. Press “Record keys”, then hold the combination you want (Esc cancels). Rebinding takes effect immediately on save.

    Command mode

    Hold the command hotkey, say an instruction (“make this more formal”, “translate to English”) and release: Parla sends it with any selected text to OpenAI and pastes the reply. Dictation never goes through an LLM.

    Needs an OpenAI API key: add one under Transcription → OpenAI, or set OPENAI_API_KEY.

    Two or more modifiers held together, no other key (default LCtrl+Shift: left Ctrl and either Shift). LCtrl/RCtrl, LShift/RShift and LWin/RWin pick one side; Alt is left Alt only, never AltGr. Press “Record keys”, hold the modifiers, then release them. It applies on save.

    Say “ricordami di chiamare Luca domani alle 15” and Parla creates a To-do with a Reminder in your Traccia, over your tailnet.

    Needs command mode on, and the Traccia URL and token below.

    Create the token on the Traccia server with traccia token create --name parla --actor you --scope todos: it can only reach To-dos and the Project list.

    While I speak

    Cloud dictations stream as you talk; the local model transcribes each phrase at your pauses, so only the last one is left when you stop. Parla then pastes the complete transcript. If this fails, Parla uses the saved recording.

    A discreet two-line preview. Your text box stays untouched until the final paste. With the local model, captions update phrase by phrase.

    Startup and setup

    Opens the first-run guide: microphone, engine, a test dictation and Start with Windows. It changes only what you change in it.

    Other audio

    Music and calls while you dictate.

    Music and other apps play quieter while you dictate, then return to their volume. Nothing is paused.

    10–90 % of each app's own volume. 30 % sounds about half as loud as you set it.

    Vocabulary

    Names and terms you want recognised.

    One term per line, up to 100 terms of 50 characters. Optional recognition hints for supported cloud models. Italian and English are recognized automatically; hints do not rewrite your transcript.

    Clipboard

    How Parla pastes and restores your clipboard.

    Use longer paste delays if an app misses or changes pasted text.

    End a dictation with “send” or “invia” to paste it without that word and press Enter.

    While you speak, check whether a text field has focus. For now Parla only writes the result to its log; pasting is unchanged.

    How long Parla waits after pasting before restoring your previous clipboard (50–2000 ms). Raise it if a slow app pastes the old clipboard.

    Updates

    Parla updates itself from its GitHub releases. Every update is signed; Parla checks the signature before it installs.

    Version

    Look for a new version once a day in the background and tell you. Nothing installs until you choose Install.
